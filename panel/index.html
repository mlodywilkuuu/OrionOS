Jak publikować zmiany?

Wybierz plik, wczytaj jego aktualną wersję, edytuj zawartość i zatwierdź commit. GitHub Pages opublikuje zmianę automatycznie po zakończeniu procesu wdrażania.

Panel nie omija zabezpieczeń GitHuba. Każdy zapis jest osobnym commitem na gałęzi main i pozostawia historię zmian.

Bezpieczeństwo

Panel korzysta z tokenu GitHub przekazanego przez administratora.

  • Token pozostaje wyłącznie w pamięci bieżącej karty.
  • Wymagany zakres: Contents — Read and write, tylko repozytorium OrionOS.
  • Nie udostępniaj tokenu i nie umieszczaj go w kodzie strony.
  • Każda zmiana jest zatwierdzana przez GitHub i widoczna w historii commitów.
To panel statyczny GitHub Pages. Nie ma własnego serwera ani bezpiecznego systemu kont. Dostęp do zapisu kontroluje token GitHub.

Pomoc i status

Panel administracyjny OrionOS Control Center.

Po zapisaniu pliku GitHub Pages może potrzebować chwili na publikację. Stan wdrożenia sprawdzisz w zakładce GitHub Actions.

Jeśli zapis się nie powiedzie, sprawdź uprawnienia tokenu, nazwę gałęzi oraz czy plik nie został zmieniony w międzyczasie.
